# Documentação do Deck Engine

Bem-vindo à documentação técnica do Deck Engine, o motor de processamento de tarefas flexível e modular.

O Deck Engine é construído em torno de uma metáfora de "jogo de cartas" para tornar o conceito de execução de tarefas mais intuitivo e gerenciável.

## Sumário

1.  **[Arquitetura Geral](./architecture.md)**

    - Entenda a filosofia por trás do Deck Engine e a metáfora de Decks, Cartas, Partidas e Arenas.

2.  **[Componentes do Engine](./engine.md)**

    - Um mergulho profundo nos sistemas que formam o coração do Deck Engine: `ArenaSystem`, `DeckSystem`, `MatchSystem`, e mais.

3.  **[Módulos Avançados (V2)](./v2-modules.md)**

    - Explore os componentes de próxima geração projetados para produção, incluindo `DomainManager`, `UnifiedLogger`, `PlatformAdapter` e `RouteManager`.

4.  **[Guia de Uso](./usage.md)**
    - Exemplos práticos de como instanciar o engine, criar decks e executar tarefas (partidas).

## Como Navegar

Recomendamos começar pela **Arquitetura Geral** para obter uma compreensão conceitual antes de explorar os detalhes de implementação nos outros documentos.
