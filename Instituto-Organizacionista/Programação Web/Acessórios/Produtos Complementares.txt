# Hacker-book - NUKTPLS-CLI

🐙 Eugenia 3.0 - As Crianças CTO's - Volume 1 🐙
Este é o primeiro universo literário cibernético disponível também como um pacote Node.js. O e-book oferece uma experiência imersiva que pode ser acessada através da CLI.

Instalação da CLI: Para instalar o NUKTPLS-CLI, basta executar o comando abaixo no seu Terminal: 


```
npm i -g nuktpls-cli
```

Início: Após a instalação, você pode iniciar o conteúdo imersivo com: nuktpls

Mais informações: nuktpls-cli no npm (https://www.npmjs.com/package/nuktpls-cli)

# Tema Edu4Dev para VSCode

Para uma experiência de programação personalizada, o Tema Edu4Dev oferece uma paleta de cores pensada para desenvolvedores e pode ser baixado e instalado diretamente no Visual Studio Code.

Instalação no VSCode: Pressione Ctrl + Shift + X para abrir a aba de extensões no VSCode e pesquise por "Edu4Dev". Selecione o tema e clique em Instalar.
Instalação via link: Edu4Dev no Marketplace do VSCode (https://marketplace.visualstudio.com/items?itemName=Edu4Dev.vscode-edu4dev-color-theme)
