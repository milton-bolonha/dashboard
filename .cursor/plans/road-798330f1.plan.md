# Roadmap de Migração Next 16 + Auth + Data

## 1. Preparação e Turbopack

- Auditar `next.config` e remover/portar configurações de webpack antigas para a chave `turbopack`, validando build + dev em todos os workspaces.
- Revisar middlewares legacy (`dashboard/middleware.js`) e migrar para a convenção `proxy.ts` ou desativar temporariamente até o Clerk entrar.
- Garantir que dependências comuns (ex.: UI libs) estão em workspaces corretos e sem conflitos de versão.

## 2. Persistência MongoDB

- Definir modelos (`users`, `workspaces`, `tiles`, `contacts`, `notes`, `usageCounters`) e helpers de acesso no workspace principal.
- Atualizar APIs (`/api/generate`, `/api/workspace/**`) para usar Mongo, mantendo fallback de leitura do cache local durante a transição.
- Criar rotina de migração: ao detectar upgrade/login, sincronizar snapshots do localStorage para o Mongo.
- Instrumentar logs métricas (tempo de geração, falhas) para monitorar a mudança.

## 3. Autenticação Clerk + Stripe

- Configurar `@clerk/nextjs` (providers, proxy, hooks) e substituir o membership fake pelo Clerk userId + plano persistido no Mongo.
- Integrar webhooks Stripe para atualizar status do plano e limites; refletir no `MembershipProvider` (agora lendo do backend).
- Atualizar UI: header mostra usuário autenticado, botões usam rota real, aplicações respeitam limites server-side.
- Cobrir fluxo completo (guest → upgrade → login → uso ilimitado) com testes E2E e atualizar docs/env (`.env.template`).
