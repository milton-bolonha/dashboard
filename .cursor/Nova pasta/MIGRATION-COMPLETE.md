
### **3. Framework TE[i]As Integrado**

```
T - Topologia: estrutura do sistema
E - Estado: status atual
[i] - Iterabilidade: o que se repete
A - Agente: quem executa
s - Subagente: quem apoia
```

### **4. Complexidade Cognitiva Controlada**

- Máximo 10 pontos por função
- Extrair condições complexas
- Evitar aninhamento profundo
- Nomes que explicam

### **5. Metáfora Cards/Decks para Pipelines**

```
Card = unidade mínima de processamento
Deck = sequência organizada para missão
Partida = execução do pipeline
Arena = ambiente de execução
```

### **✅ Padrões Identificados e Documentados**

```json
{
  "name": "dev-workspace",
  "private": true,              # ✅ Nunca publicar workspace
  "type": "module",            # ✅ ESM por padrão
  "workspaces": ["ai", "dashboard", "gatsby-landing"],

  "scripts": {
    // ✅ Padrão workspace:ação
    "ai:setup": "ai-workspace setup",
    "dash:dev": "npm --workspace=dashboard run dev",
    "landing:build": "npm --workspace=gatsby-landing run build"
  }
}
```
