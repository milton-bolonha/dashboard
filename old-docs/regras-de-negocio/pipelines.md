# Pipelines

Sequências automatizadas que transformam ações do cliente em serviços digitais ou físicos.

## Exemplo de Pipeline

**"Publicar e Imprimir"**
1. Cliente usa a View "Print"
2. Gera PDF com conteúdo
3. Aciona serviço de impressão e entrega física
4. Registro na fatura

## Tipos de Pipeline

- Geração de PDF
- Integração com APIs
- Impressão sob demanda
- Envio de notificações
