# Addons

Addons são recursos que expandem as capacidades da conta do cliente.

## Exemplos

| Nome              | Tipo     | Preço         | Plano incluso? |
|-------------------|----------|---------------|----------------|
| Upload de imagem  | Feature  | R$10/mês      | Pro / Unlimited|
| Embed de vídeo    | Tiered   | R$1/5 vídeos  | Apenas Unlimited |
| Kanban View       | View     | R$15/mês      | Não incluso    |
| API Requests      | Metered  | R$0.01/chamada| Não incluso    |
