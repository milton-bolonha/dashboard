# Serviços

Serviços são entregas ou ações geradas por Views ou Pipelines.

## Tipos

| Serviço            | Tipo      | Modelo de cobrança      |
|--------------------|-----------|--------------------------|
| Geração de PDF     | Virtual   | R$0.50 por geração       |
| Impressão sob demanda | Física | R$25 por unidade         |
| API / Webhook      | Virtual   | Incluso ou metered       |
