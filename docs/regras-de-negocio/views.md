# Views

As Views são componentes visuais e funcionais conectados a Sections ou diretamente ao front/admin.

## Tipos de Views

| Nome       | Tipo     | Descrição                     |
|------------|----------|-------------------------------|
| Formulário | Admin    | Captura dados no dashboard    |
| Galeria    | Público  | Exibição visual de imagens    |
| Kanban     | Admin    | Organização por colunas       |
| Mini-site  | Público  | Landing page personalizável   |
| Checkout   | Público  | Integração com pagamentos     |

## Comercialização

- Podem ser parte de um plano
- Podem ser adquiridas individualmente
- Podem ativar serviços (ex: PDF, impressão)
