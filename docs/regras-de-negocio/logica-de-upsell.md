# Lógica de Upsell

## Situações de Upgrade

- Ao atingir limite de uso (itens, sections)
- Ao tentar ativar um addon não incluso
- Ao tentar acessar uma View premium

## Estratégias

- Pop-up com botão direto para Stripe Portal
- Compra avulsa sem mudar o plano
- Combos promocionais (ex: 3 addons por R$25)

## Gatilhos Técnicos

- Detectados via backend ou client
- Disparados por eventos de interação
